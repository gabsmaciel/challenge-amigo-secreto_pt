# 🎲 Desafio Amigo Secreto - Alura

Este projeto foi desenvolvido como parte do **Challenge da formação JavaScript** da **Alura**. O objetivo é criar uma aplicação web simples e interativa de Amigo Secreto, onde os usuários podem adicionar participantes e sortear nomes aleatoriamente.

---

## 🚀 Funcionalidades

- ✅ Adicionar nomes à lista de participantes
- ✅ Validação de entrada para impedir campos vazios
- ✅ Visualização da lista de amigos adicionados
- ✅ Sorteio aleatório de um nome da lista

---

## 🛠 Tecnologias utilizadas

- **HTML** – Estrutura da página
- **CSS** – Estilização e responsividade
- **JavaScript** – Lógica para manipulação da lista e sorteio
